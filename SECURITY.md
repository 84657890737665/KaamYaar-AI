# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within KaamYaar, please report it immediately. We take all security issues seriously.

**Do not publicly disclose the issue until it has been resolved.**

Please send an email detailing the vulnerability to our security team. Include as much information as possible, including steps to reproduce the issue.

## API Keys
**No API keys committed.**
We actively monitor and ensure that no hardcoded API keys are committed to this repository. All sensitive keys and secrets are loaded securely from environment variables.

## Data Privacy
**User phone numbers are encrypted.**
We prioritize user privacy. Sensitive personal information, such as user phone numbers, is encrypted at rest and in transit.
